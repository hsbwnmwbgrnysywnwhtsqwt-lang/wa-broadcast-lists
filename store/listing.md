## לשונית Store listing

**שם (מגיע מה-manifest):** WA רשימות תפוצה

**תיאור קצר (Summary):** מגיע מה-`description` ב-manifest:
> רשימות תפוצה ל-WhatsApp Web – לאנשי קשר ולקבוצות, עם טקסט, תמונות וסרטונים. מסמן את הנמענים, והשליחה ידנית.

**קטגוריה:** Productivity → Communication (או Workflow & Planning)

**שפה:** Hebrew (עברית)

**תיאור מלא (Description) – עברית:**

```
שולחים את אותה הודעה להרבה אנשים או להרבה קבוצות ב-WhatsApp? התוסף הזה חוסך את ההעתק-הדבק.

✅ עובד גם עם קבוצות: רשימת תפוצה יכולה לכלול אנשי קשר, קבוצות, או שילוב של שניהם – למשל כל קבוצות המתנדבים, כל כיתות ההורים או כל קבוצות הצוות, בהודעה אחת.
✅ תמונות וסרטונים: מצרפים קבצים להודעה, והתוסף שולח אותם לכל הרשימה עם ההודעה ככיתוב.

איך זה עובד:
• פותחים את WhatsApp Web ולוחצים על הכפתור הירוק בתפריט הצד של WhatsApp – נפתח פאנל צד. לחיצה נוספת סוגרת אותו.
• סורקים את אנשי הקשר והקבוצות ויוצרים רשימות תפוצה.
• בוחרים רשימה, כותבים הודעה ולוחצים "שלח".
• התוסף פותח את חלון "שלח אל" של WhatsApp עם ההודעה ומסמן עד 5 נמענים (אנשי קשר או קבוצות) בכל סבב.
• אתם לוחצים על כפתור השליחה של WhatsApp – והסבב הבא נפתח לבד, עד שכולם קיבלו את ההודעה.
• עם תמונה או סרטון: הנמען הראשון מקבל את ההודעה בשיחה שלו, ואז התוסף מעביר אותה לשאר – 5 נמענים בכל לחיצה (הודעה שכתבתם בעצמכם ומעבירים לא מסומנת "הועברה"). עם כמה קבצים – נמען אחד בכל פעם.

מה עוד יש:
• סטטוס לכל נמען ולכל קבוצה: נשלח / ממתין / לא נמצא. אם עצרתם באמצע – ממשיכים מאותה נקודה.
• כותבים הודעה חדשה – והשליחה מתחילה מחדש לכל הרשימה.
• מיון לפי א״ב, המסומנים למעלה, ומספרי טלפון בסוף. יש גם חיפוש.
• סריקה עם ספירה לאחור, והמסך של WhatsApp ננעל בזמן הסריקה כדי שלא תפריעו לה בטעות.
• גיבוי וייבוא של הרשימות לקובץ – להעברה בין מחשבים.
• התוסף פעיל רק ב-web.whatsapp.com ולא בשום אתר אחר.

פרטיות:
כל הנתונים (רשימות, שמות אנשי קשר וקבוצות, והודעות) נשמרים רק בדפדפן שלכם. תמונות וסרטונים שמצרפים מועברים רק ל-WhatsApp Web בדפדפן ולא נשמרים. התוסף לא שולח שום מידע לשרת כלשהו, ולא שולח הודעות בעצמו – את השליחה תמיד מאשרים ידנית בלחיצה על כפתור השליחה של WhatsApp.
```

**Description – English (אם מוסיפים תרגום):**

```
Send the same message to many people – or many groups – on WhatsApp Web without copy-pasting.

✅ Works with groups too: a broadcast list can contain contacts, groups, or both – for example all your volunteer groups, class parent groups or team groups, in one message.
✅ Images and videos: attach files to the message and send them to the whole list, with the message as the caption.

How it works:
• Open WhatsApp Web and click the green button added to WhatsApp's side menu – a side panel opens. Click again to close it.
• Scan your contacts and groups and create broadcast lists.
• Pick a list, write a message and click "Send".
• The extension opens WhatsApp's "Send to" dialog with your message and pre-selects up to 5 recipients (contacts or groups) per round.
• You click WhatsApp's send button yourself – the next round opens automatically until everyone got the message.
• With an image or video: the first recipient gets the message in their chat, then the extension forwards that same message to the rest – 5 recipients per click (your own forwarded messages are not labeled "Forwarded"). With several files – one recipient at a time.

Also:
• Per-recipient status (sent / pending / not found) and resume where you stopped.
• Write a new message and sending starts over for the whole list.
• Sorted alphabetically, selected ones on top, phone numbers last, with search.
• Scan with a countdown; WhatsApp's screen is locked during the scan so it isn't interrupted.
• Backup and import of your lists to a file.
• Active only on web.whatsapp.com.

Privacy:
All data (lists, contact and group names, messages) stays in your browser. Attached images and videos are only passed to WhatsApp Web in your browser and are not stored. The extension sends no data to any server and never sends messages on its own – you always confirm each send.

This extension is not affiliated with, endorsed by, or sponsored by WhatsApp or Meta. WhatsApp is a trademark of WhatsApp LLC.
```

## לשונית Privacy practices (פרטיות)

**Single purpose description (תיאור מטרה יחידה):**
```
Lets the user create broadcast lists from their WhatsApp Web contacts and groups and send one message (text, optionally with images or videos) to a whole list: for text, the extension opens WhatsApp Web's own "Send to" dialog and pre-selects list members, up to 5 per round; with images or videos, it attaches the files with the message as the caption in the first recipient's chat and then opens WhatsApp's own "Forward" dialog for that message, pre-selecting up to 5 recipients per round. The user always clicks WhatsApp's send button manually; the extension never sends messages on its own.
```

**הצדקת sidePanel:**
```
The extension's entire user interface (broadcast lists, contact and group selection, message editor and send progress) is shown in a side panel next to WhatsApp Web. The side panel is enabled only on web.whatsapp.com tabs.
```

**הצדקת storage:**
```
Stores the user's broadcast lists, scanned contact and group names, message drafts and per-recipient send status locally with chrome.storage.local, so lists persist between sessions. Nothing is synced or transmitted anywhere.
```

**הצדקת הרשאת מארח:**
```
The content script runs only on https://web.whatsapp.com/*. It is required to: (1) add a button to WhatsApp Web's side menu that opens the extension's side panel, (2) read contact and group names from WhatsApp's "Send to" dialog when the user clicks "Scan", (3) tick the selected recipients in that dialog, and (4) when the user attached images or videos, open a recipient's chat, attach those files with the message as the caption, and open WhatsApp's "Forward" dialog for that message to pre-select the next recipients. The extension does not run on any other site and makes no network requests.
```

**קוד מרוחק:** לא נעשה שימוש בקוד מרוחק.

## הוראות הבדיקה (בתפריט "גישה")

```
The extension works only on https://web.whatsapp.com and requires the reviewer to log in to WhatsApp Web with their own WhatsApp account (scan the QR code with a phone). No test credentials are needed for the extension itself.

1. Open https://web.whatsapp.com and log in.
2. Click the green round button added to WhatsApp's left menu (below Communities), or the extension's toolbar icon, to open the side panel.
3. Click "סרוק מ-WhatsApp" (Scan) – the extension reads contact and group names from WhatsApp's "Send to" dialog (the screen is locked for a few seconds during the scan).
4. Click "+ רשימה חדשה" (New list), enter a name, tick a few contacts and/or groups and click "שמור רשימה" (Save).
5. Open the list, type a message and click "שלח" (Send). WhatsApp's "Send to" dialog opens with the message and the recipients pre-selected (up to 5 per round).
6. The reviewer clicks WhatsApp's own green send button. The next round opens automatically. The extension never clicks send by itself.

All data is stored locally in chrome.storage.local; the extension makes no network requests.
```
